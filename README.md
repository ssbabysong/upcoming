# Upcoming 行程本

规划未来旅行的小工具：什么时候去哪里，每天做什么，一眼看清。

## 功能

- **下一站登机牌**：首页置顶最近一次行程，显示倒计时（T-minus）或「第几天」
- **时间线**：按月份排列所有行程，显示两次旅行之间的间隔天数，日期重叠时会提醒
- **日历**：月视图显示每天在哪里，点空白日期直接从这天新建行程
- **每日行程单**：每个行程按 D1、D2…列出航班、火车、住宿、活动、餐厅，地点可一键打开 Google 地图
- **导出到日历**：导出 `.ics`，可以导入 Google 日历、Apple 日历或 Outlook
- **备份 / 换设备**：导出、导入 JSON

## 使用

单个文件，无需安装或构建：直接用浏览器打开 `index.html`，或部署到 GitHub Pages
（Settings → Pages → 选择分支和根目录）。

数据保存在浏览器的 localStorage 里。以 Claude Artifact 形式打开时，会额外同步到你的账户（仅你本人可见）。
